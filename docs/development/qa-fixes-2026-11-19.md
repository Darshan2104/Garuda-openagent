- `python scripts/check_docs.py --commands` passed.
- The complete `tests/browser/run_checks.py --keep` suite passed in real Chrome,
  including uploads, URL grounding, approvals, native previews and starter flows.
- The wheel built and passed imports, CLI parsing, shared conversation service,
  all packaged starters and dashboard-asset checks from an independent install.

0.17.5; the unchanged diagnostics test and lint pass with that toolchain.

The combined run also exposed an unpriced partial-stream accounting interaction.
PR #542 restored the existing conservative reservation charge for that path.
The spending, accounting and streaming owner suites passed together after the
correction. The initial combined full-suite result includes it.

local protocol peers. They cover authority/refusal cases, real uv/pytest
invalidation, tool execution, cancellation ordering, persisted checkpoints and
actual native conversation resume. No paid inference or vendor login is needed.
